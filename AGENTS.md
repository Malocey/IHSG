# Anweisungen für Agenten (Jules)

Hallo! Wenn du an diesem Projekt arbeitest, befolge bitte die folgenden Regeln, um eine reibungslose Zusammenarbeit und eine saubere Dokumentation zu gewährleisten.

## 1. Lies das Changelog

**Bevor du mit einer neuen Aufgabe beginnst**, lies die `CHANGELOG.md`-Datei sorgfältig durch. Sie gibt dir einen Überblick über alle bisherigen Änderungen und den aktuellen Stand des Projekts. Dies ist entscheidend, um deine Arbeit auf dem aktuellen Code aufzubauen.

## 2. Aktualisiere das Changelog

**Nachdem du deine Aufgabe abgeschlossen hast und bevor du deine Änderungen einreichst (submit)**, musst du einen neuen Eintrag in der `CHANGELOG.md` hinzufügen.

- Füge deine Änderungen unter der Sektion `## [Unreleased]` hinzu.
- Verwende die bestehenden Kategorien (`### Hinzugefügt`, `### Geändert`, `### Behoben` etc.) oder erstelle neue, falls passend.
- Beschreibe deine Änderungen kurz und präzise.

## 3. Allgemeine Konventionen

- **Sprache:** Der gesamte Python-Code (Variablen, Funktionen, etc.) muss auf **Englisch** sein. Alle Kommentare im Code müssen auf **Deutsch** sein.
- **Framework:** Das Projekt verwendet das **Kivy**-Framework.
- **Projektziele:** Das Hauptziel ist ein Idle-Horde-Slayer-Spiel mit tiefgreifenden Progressionssystemen. Das visuelle Ziel ist ein "HD-2D"-Stil, inspiriert von Spielen wie Octopath Traveler und Vampire Survivors.

Diese Regeln sind entscheidend für den Erfolg dieses Projekts. Deine Kooperation wird sehr geschätzt.

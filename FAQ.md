# FAQ - Häufig gestellte Fragen

Hier finden Sie Antworten auf häufig gestellte Fragen zum Spiel "Idle Horde Slayer".

## 1. Gameplay

**F: Was ist das Ziel des Spiels?**
A: "Idle Horde Slayer" ist ein Idle-Spiel. Der Held kämpft automatisch gegen endlose Wellen von Gegnern. Ihre Aufgabe als Spieler ist es, den Helden durch eine Vielzahl von Upgrade-Systemen zu verstärken und ihn so immer mächtiger zu machen, um schwierigere Herausforderungen zu meistern.

**F: Wie funktioniert das Upgrade-System?**
A: Das Spiel kombiniert drei Haupt-Progressionsebenen:
1.  **Temporäre Upgrades (In-Run):** Während eines Laufs sammeln Sie XP-Kristalle. Bei einem Level-Up wählen Sie eine von drei zufälligen Verbesserungen, die nur für den aktuellen Run gelten.
2.  **Permanenter Skill-Tree:** Mit Skill-Punkten schalten Sie dauerhafte Boni in einem großen, passiven Fähigkeitenbaum frei.
3.  **Meta-Progression (Stadt):**
    - **Ausrüstung:** Gegner können Ausrüstungsgegenstände fallen lassen, die Sie im Ausrüstungs-Menü anlegen können, um permanente Boni zu erhalten.
    - **Shop:** Mit Gold, das von Gegnern fallen gelassen wird, können Sie im Händler-Shop dauerhafte, prozentuale Boni kaufen (z.B. mehr Gold- oder XP-Gewinn).

**F: Was sind die verschiedenen Währungen?**
A: Es gibt aktuell drei Währungen:
- **Gold:** Eine häufige Währung zum Kaufen von Shop-Upgrades.
- **Seelenessenz:** Eine seltene Währung, deren Nutzen für zukünftige Features wie Crafting geplant ist.
- **Skill-Punkte:** Werden zum Freischalten von Knoten im Skill-Tree verwendet.

**F: Kann ich den Helden direkt steuern?**
A: Nein, das Kernkonzept ist "Idle". Der Held bewegt und kämpft von allein. Der Fokus des Spielers liegt auf strategischen Entscheidungen bei den Upgrades und der Verwaltung der Ausrüstung.

## 2. Technik & Assets

**F: Welche Engine wird verwendet?**
A: Das Spiel wird mit dem **Kivy-Framework** in Python entwickelt.

**F: Woher stammen die Grafiken?**
A: Die Assets sind eine Kombination aus verschiedenen frei verfügbaren Pixel-Art-Quellen. Die Hauptquellen sind im `README.md` und der `documentation.md` verlinkt.

**F: Wie kann ich meinen Spielstand sichern oder übertragen?**
A: Im "Stadt"-Bildschirm gibt es einen "Einstellungen"-Bereich. Dort finden Sie Optionen, um Ihren Spielstand (`player_save.json`) in einen separaten Ordner zu **exportieren** und von dort wieder zu **importieren**.

## 3. Zukünftige Entwicklung

**F: Welche Features sind als Nächstes geplant?**
A: Die Roadmap umfasst unter anderem:
- Einführung von aktiven, vom Spieler auslösbaren Fähigkeiten.
- Mehr Gegnervielfalt mit einzigartigen Verhaltensmustern.
- Ein Crafting-System beim Schmied, das Seelenessenz verwendet.
- Visuelle Effekte wie Partikelsysteme und dynamische Beleuchtung.
- Ein lokaler Koop-Modus (Shared- oder Split-Screen).

**F: Wie kann ich zur Entwicklung beitragen?**
A: Das Projekt ist derzeit in einer frühen Phase. Zukünftig könnten Beiträge aus der Community in Betracht gezogen werden. Halten Sie Ausschau nach Updates in der `README.md`.
